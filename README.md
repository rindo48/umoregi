# 埋もれ木

アルゴリズムを通さずに、埋もれたものを自分の手で掘り出すための道具箱。

## 開き方

- **ネットで：** https://rindo48.github.io/umoregi/ （スマホでもそのまま開ける）
- **手元で：** `埋もれ木.html`（または `index.html`）をダブルクリック。Chrome か Edge がおすすめ。

どちらもインターネットにつながっている必要がある（各アーカイブに直接問い合わせるため）。
ネットで開いた場合、電波の部屋では https で配信している局だけが鳴る。

## 部屋

| 部屋 | 掘るもの | 深さの物差し |
| --- | --- | --- |
| 音盤 | Internet Archive の録音（SP盤、名もなきカセット、古いラジオ、野の音…） | archive.org での再生回数 |
| 電波 | 世界のネットラジオ局。経度のダイヤルで国を選ぶ | 今日その局に合わせた人数 |
| ジャケ | MusicBrainz に記録された盤。名前を伏せてジャケットだけで選ぶ | （人気を使わない） |
| 映像 | VHS、ホームムービー、古いCM、町のケーブルテレビ。撮ったまま投稿された動画への骰子 | archive.org での再生回数 |
| 収蔵庫 | ジャパンサーチ、メトロポリタン美術館、クリーブランド美術館 | 展示室に出ていないもの |
| 頁 | Wikipedia（でたらめ、主題、近くの場所） | この30日の閲覧数 |
| 片隅 | 個人ブログや手作りのホームページへ漂着 | （順位がない場所） |
| 市 | ありそうでない品を、手作り・中古の市で新着順に探す | （新着順） |
| 札 | 画面の外で掘るための札と、行き先を決めない散歩の手順 | — |
| 標本箱 | 拾ったものと、拾うときに書いた自分の言葉 | — |

キー操作：`N` で次を掘る、`K` で拾う。

## この道具がしないこと

- あなたの好みを覚えて、次に見せるものを選ぶこと
- 人気順に並べること
- 標本箱の中身をどこかへ送ること（開いたブラウザの中にだけ保存される）

標本箱はブラウザごとに別々。ブラウザのデータを消すと標本箱も消えるので、ときどき標本箱の「書き出す（控え）」で控えを取っておくと安心。別の端末へは「控えを読み込む」で移せる。

## 手を入れたいとき

中身は `src/` にある（`index.html`、`css/style.css`、`js/` の下の部屋ごとのファイル）。
書き換えたら `python build.py` で `埋もれ木.html` と `index.html` を作り直す。
鍵語や札の文言は `src/js/data.js` にまとめてある。自分の言葉に差し替えていい。
